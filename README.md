# Forever Name Forge

Character and guild names for every race and class in WoW Forever, plus a dice roller for a random character.

Open it here: https://varkxp.github.io/name-forge/

On a phone, use your browser's "Add to Home Screen" or "Install app" option to keep it as an app. It works offline once installed.

Banner art is official World of Warcraft artwork by Alex Horley, used here for a fan project.
